## Install

**Zen or Firefox:** download `sift-{{V}}.xpi` below and drag it onto a browser window (or `about:addons` → gear → *Install Add-on From File...*), then click **Add**. It's signed by Mozilla and updates itself from now on.

**Chrome, Edge, Brave, Opera, Vivaldi:** download `sift-{{V}}-chrome.zip` and unzip it to a folder you'll keep. Open `chrome://extensions` (or `edge://extensions`, `brave://extensions`), turn on **Developer mode**, click **Load unpacked** and pick that folder. To update later, unzip the new version over the same folder and press the reload arrow on Sift's card.
