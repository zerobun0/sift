YouTube API key optional

Only needed for category filtering (Travel, Education, Music...). Length, Shorts, live, watched, title words, channels and your YouTube topics all work without it.

YouTube leaves a video's category out of the feed. Without a key, Sift only knows the categories of videos you have opened. With your own free key it asks YouTube directly. The key stays in this browser and is sent only to YouTube.

How to get a key (5 minutes, free)
  1. Open console.cloud.google.com and create a project.
  2. APIs & Services, Library: enable "YouTube Data API v3".
  3. Credentials, Create credentials, API key.
  4. Edit the key: API restrictions, YouTube Data API v3 only.
